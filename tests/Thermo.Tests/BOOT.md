# BOOT.md — Thermo.Tests

## Purpose

The definition of what "`Thermo` is ready" means.

| Level | What it checks | Against what (source of truth) | State |
|---|---|---|---|
| L0 | `Cp°/R`, `H°/RT`, `S°/R`, `G°/RT` per species and temperature; interval selection and extrapolation; the constant R | fixtures generated by an independent Python evaluation of the same records and the value of `cea.R` (fixtures node); NIST-JANAF spot values typed into a fixture with their source | ⏳ |
| L1 | the table builder: order, gaseous-first split, stoichiometry matrix, refusal of foreign elements, limits | the `Data` records of the same species (list generated from the table) | ⏳ |
| L1 | the same functions inside an ILGPU kernel on the CPU accelerator give the same bits as the host call | the host call | ⏳ |
| Protocol | the tree invariant, documents against code | `AGENTS.md`, the surface snapshot | ⏳ |

## Invariants

- **The reference is files**: generated fixtures from the fixtures node, JANAF values
  in a fixture with the table's precision and citation.
- **Tolerances are derived**: 1e-12 relative against the independent evaluation of the
  same polynomials (double arithmetic, different code); the NASA report's stated fit
  accuracy against JANAF; zero ULP between host and CPU-accelerator kernel.
- Kernel tests create their own ILGPU context with the CPU accelerator; no CUDA.

## Dependencies

- [Thermo](../../src/Thermo/API.md) — what is being checked.
- [Data](../../src/Data/API.md) — loading the database the tables are built from.
- [Fixtures](../Fixtures/API.md) — the generated function values and the R value.

Outside the tree: xunit; ILGPU 1.5.3 (CPU accelerator only).

## Constraints

- Part of the default test command; no CUDA involved.
- Paths from the repository root; no writes into the working directory.

## Acceptance criteria

- [ ] L0 green against the generated fixtures and the JANAF fixture (date, test names).
- [ ] L1 builder and kernel-equality tests green (date, test names).
- [ ] Every check proven non-degenerate once: a coefficient swapped in a fixture, the
      interval rule altered, a stoichiometry entry changed, each seen red.

## Taboos

- Do not loosen a tolerance for green.
- Do not compute the expected value in the test with the code under test.
- Do not skip when a fixture is missing: that is a failure.
