# BOOT.md — Thermo.Tests

## Purpose

The definition of what "`Thermo` is ready" means.

| Level | What it checks | Against what (source of truth) | State |
|---|---|---|---|
| L0 | `Cp°/R`, `H°/RT`, `S°/R`, `G°/RT` per species and temperature; interval selection and extrapolation; the constant R | fixtures generated by an independent Python evaluation of the same records and the value of `cea.R` (fixtures node); NIST-JANAF spot values typed into `janaf.json` with their source | ✅ 2026-09-12 |
| L1 | the table builder: order, gaseous-first split, stoichiometry matrix, flattened intervals, refusal of foreign elements, duplicates and reactant-only records, limits | the `Data` records of the same species (list generated from the table) | ✅ 2026-09-12 |
| L1 | the same functions inside an ILGPU kernel on the CPU accelerator give the same bits as the host call | the host call | ✅ 2026-09-12 |
| Protocol | the tree invariant, documents against code | `AGENTS.md`, the surface snapshot | ⏳ |

## Invariants

- **The reference is files**: generated fixtures from the fixtures node, JANAF values
  in a fixture with the table's precision and citation.
- **Tolerances are derived**: the `thermoFunction` entry of the fixtures node's table
  (1e-12, double arithmetic of the same polynomials in different code) against the
  generated fixtures; a per-species tolerance recorded in `janaf.json` with its reason
  against JANAF; zero ULP between host and CPU-accelerator kernel.

  ⚠ 2026-09-12: stood "the NASA report's stated fit accuracy against JANAF" (0.1 %).
  The records' sources are Gurvich et al. and Woolley, not JANAF, and differ from it by
  up to 1.9 % (`H2O` at 3000 K); the tolerance lives per species in the fixture with the
  observed deviation. Details in the Thermo node's acceptance criteria.
- Kernel tests create their own ILGPU context with the CPU accelerator; no CUDA.

## Dependencies

- [Thermo](../../src/Thermo/API.md) — what is being checked.

## Constraints

- Part of the default test command; no CUDA involved.
- Paths from the repository root; no writes into the working directory.
