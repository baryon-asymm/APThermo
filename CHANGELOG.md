## [Unreleased]

### Added
- Initial public release of the APThermo library and command line tool.
- `apthermo` CLI: rocket, equilibrium, states, species, devices, and schema commands.
- NuGet package `APThermo` (merged assembly) and `APThermo.Cli` (dotnet tool).
- Sample scenarios: RocketSolve, BatchSolve, EquilibriumSolve, StatesSolve.
- Task-oriented guide under `docs/guide/`.
- JSON Schemas embedded in the CLI (`apthermo schema <name>`).
- Documentation tests (Docs.Tests): snippets, approved outputs, links, schemas, guide shape.
